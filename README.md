# How to use Claude

A reusable skill for planning, configuring, and verifying personal VPS routing for official Claude clients on Windows and iPhone.

The skill emphasizes narrow routing, evidence-based acceptance, safe rollback, and keeping private node material out of public files. It does not provide methods to evade regional eligibility, identity checks, account enforcement, or service safeguards.

## Install

Copy this repository's `SKILL.md` into a skill folder named `how-to-use-claude` under your agent's skills directory. For example:

- Claude Code: `~/.claude/skills/how-to-use-claude/SKILL.md`
- Codex: `~/.codex/skills/how-to-use-claude/SKILL.md`

Then start a new session or invoke the skill according to that agent's skill workflow.
